# Subnetting Simulation

A polished subnetting calculator and visual explainer built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- Interactive IP and CIDR calculator
- Binary IP and subnet mask visualization
- Step-by-step subnet explanation
- Address space and subnet splitting views
- Clean, responsive dark UI

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deploy to Vercel

This project is ready for Vercel as a static SPA.

- Build command: `npm run build`
- Output directory: `dist`

The included `vercel.json` handles client-side routing for SPA deployments.
